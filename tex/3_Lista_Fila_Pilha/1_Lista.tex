\begin{frame}[label=notas]
	\begin{itemize}
		\item Conjunto ordenado de EDs com acesso \emph{sequencial} onde inclusão, 
		exclusão e consulta de seus elementos podem acontecer de forma aleatória
		%Uma coleção de dados homogênea;Itens dispostos em seqüência;Quantificável;Ordenável;

				\item Aberta - o último nó aponta para nada
				\item Fechada - o último nó aponta para o primeiro
				\pause
				\item Simplesmente Encadeada
					\vspace{-.5\baselineskip}
					\begin{columns}

							%source: http://en.wikipedia.org/wiki/File:Singly-linked-list.svg

				\vfill
				\item Duplamente Encadeada
					\vspace{-.5\baselineskip}
					\begin{columns}
						\column{.1\textwidth}
						\column{.45\textwidth}
							\begin{itemize}

		\item Desvantagem: acesso sequencial

\begin{frame}[label=notas]
	\framesubtitle{\subsecname\ Aberta Simplesmente Encadeada}

	Aplicação: Soma de inteiros (super) longos
	\\\vfill
	O hardware  da maioria dos computadores só permite inteiros de um tamanho máximo específico. Como representar inteiros positivos de tamanhos arbitrariamente grandes? 
	\\\vfill\pause
	Usando uma lista para armazenar pedaços valor: 
cada nó armazena alguns dígitos do número. Por exemplo, o 
número 1234 5678 9012 3456, seria armazenado como:

	\begin{figure}
		\centering
		\begin{tikzpicture}[node distance=2em,minimum width=5em, minimum height=1.8em]
			\node[block] (b1) {3456};
			\node[block, right=of b1] (b2) {9012} edge[line, <-] (b1);
			\node[block, right=of b2] (b3) {5678} edge[line, <-] (b2);
			\node[block, right=of b3] (b4) {1234} edge[line, <-] (b3);
		\end{tikzpicture}
	\end{figure}		
\end{frame}

\begin{frame}[fragile]
	\framesubtitle{Inversão ($O(n)$)}
	\pause
	\begin{center}
	\begin{minipage}{.45\textwidth}
		\begin{lstlisting}[morekeywords={inverte, no}]
			inverte(lista)
			    no inv := emptyset
			    no aux

			    enquanto(lista != emptyset)
			        aux := lista
			        lista := lista.prox
			        aux.prox := inv
			        inv := aux
			    lista := inv
		\end{lstlisting}
	\end{minipage}
	\end{center}
\end{frame}
